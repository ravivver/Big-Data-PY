# Sistema de Simulação e Gestão de Estoque (Big Data PY)

Este projeto simula um sistema básico de gestão de estoque, demanda e lucro utilizando as bibliotecas `Pandas` e `Matplotlib` para análise de dados e `Scikit-learn` para previsão.

---

### 1 Dependências

O projeto utiliza bibliotecas específicas. instale todas elas usando o arquivo `requirements.txt`.

1.  **Abra o PowerShell/VS Code Terminal**
2.  **Navegue até o diretório** onde o arquivo `trabalho.py` e `requirements.txt` estão localizados:
    ```bash
    cd D:\caminho\para\sua\pasta\bigdata-py
    ```
3.  **Instale todas as dependências** necessárias:
    ```bash
    python -m pip install -r requirements.txt
    ```

---

## 2. Utilizando

Inicie com:

```bash
python trabalho.py
```
